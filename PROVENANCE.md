# Source provenance and release checklist

## What was collected

- `recokt/probe.py`: portable adaptation of the main per-school training worker snapshot (`probe_v2.py`, SHA-256 `b54b911183ce43e425681886acac6e86687ad5a83432e67ebcae370b941c5f3e`). Only import/path setup and machine-specific STOP/resource guard were adapted; the per-school 6+6 training routines are retained. The portable caller owns scheduling and resource limits.
- `recokt/train.py`: portable coordinator derived from the main `component_worker_v1.py`; it saves the original factors and per-tensor int8 factors, floating vectors and correction head. It is new packaging code, not the original server script.
- `recokt/backbones/candidate.py`: the adapter, full revisit-head and feature routines extracted from the main experiment's `candidate_architecture_runner.py` (original SHA-256 `322f05f4044a92f75edc39a1698fa56a1cfd82f0cedbfb4d02a5ceff4259753a`).
- `recokt_vendor/*.py`: relevant baseline/model/training dependencies. Their local file hashes were checked against the recorded server source manifest.
- `recokt/backbones/keenkt.py`, `impl/KeenKT.py` and `keen_predict.py`: the causal KeenKT adapter and inference source matched recorded server SHA-256 values before package-relative imports, provenance headers and whitespace normalization. Before those packaging changes, `impl/utils.py` matched recorded server SHA `99db6650693a5ea7b13170fe737bf2782b00ccba289b58ebafc843ef507f12fa` after removing an unused local `import pandas as pd` line.
- `recokt/factor_stream.py`: DKT factor-stream snapshot SHA-256 `c76f41a0c68e2f25636072b1b859bdc88119dc19756cf9985925ce25923e625f`.
- `recokt/serving`: source-based managed-session and DKT selective-state code, with package-relative imports and a portable quantized loader. The retained-state policy was validated on DKT in the research experiment; this packaging's exact real-checkpoint end-to-end behavior is still to be verified.
- `recokt/predict.py` and `recokt/bank.py`: new portable loading, routing, one-bank training and evaluation interfaces. SAKT prediction was independently checked on a synthetic length-83 sequence against the original rolling-query implementation (maximum absolute difference below `1.2e-7` in two synthetic checks); the portable full real-data evaluator is not yet proven equivalent.
- `recokt/attacks/student.py`: portable adaptation of the frozen expanded DKT student scorer `attack_expanded_score_v3.py`; explicit paths replace server globals, and server-specific input-audit and code-hash gates are omitted. It still checks query and plan hashes. `design.py` transcribes the balanced assignment from `freeze_attack_expanded_v1.py`; `features.py` implements its query-time likelihood features from `attack_expanded_query_v1.py`; `school.py` implements the five-seed main-table Gaussian paired scoring from `privacy_score_group_v1.py` and its Gaussian fit rule. Full shadow training, provenance validation and real student records are not provided.

  Frozen source SHA-256: student scorer `1cce47cd82fee0d8557acabaf557942a6cb3f5e176df172a2b1b42adf6f8cb32`, balanced plan `6990b4b24a2419a82111e85a0d848ced6c0f7ede7a89d4073f497f8fdf9b5c4c`, query features `cf91162448a1b174700574a3889d01405f17831b26c55aca13904778491ccace`, school group scorer `9184a05a2b6a3edddf5dc25aa188ae277d7f1f139359d4d0ab110deb1c9cea72`. On synthetic 88-system inputs, the portable and original student scorers agreed on all seven attacks, thresholds, per-system metrics and 500 bootstrap replicates. On a separate synthetic example, all five school Gaussian folds and pair decisions matched the research fit/scoring rule. These checks do not establish full real-data reproduction.

## Required before public release

1. Use the exact frozen inputs, source plan and a permission-cleared small reference to compare this portable trainer and evaluator against original component tensors and per-target predictions, including DKT, SAKT and KeenKT. Full data and student-level predictions remain outside the release. Confirm package/software versions and independent metric aggregation before claiming paper reproduction.
2. Retain the project's MIT license and third-party notices, and check dataset redistribution terms. The upstream [HubuKG/KeenKT](https://github.com/HubuKG/KeenKT) project is distributed under Apache-2.0; `KEENKT_APACHE-2.0.txt` covers the upstream-derived material. The causal, skill-only BCE wrapper changes the original behavior.
3. Review any separately prepared public data/configurations and model weights for redistribution rights. This release candidate intentionally includes no datasets, trained weights, user data, private keys or server credentials.
